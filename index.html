Why humans in the loop?

I'm interested in making machine learning understandable and usable for people without programming or AI expertise, especially in clinical research. My work combines AutoML, human-computer interaction and data science, and I like building tools as much as writing about them.

PhD project

Hamelin

A no-code, protocol-aware AutoML desktop application for clinical research. Clinical researchers without coding skills can build, evaluate and document predictive models that respect clinical protocol structures which generic AutoML tools ignore. It is the core of my doctoral thesis.
