Diego García-Prieto

Teaching machines to listen to people.

Computer scientist and PhD candidate at the University of Cantabria, where I research Human-Guided Machine Learning and Human-Centered AI.

LinkedIn Google Scholar ORCID GitHub

About

I'm interested in making machine learning understandable and usable for people without programming or AI expertise, especially in clinical research. My work combines AutoML, human-computer interaction and data science, and I like building tools as much as writing about them.

My path to AI was not a straight line: satellite image recognition, malware analysis in industry, natural language processing, predictable real-time systems for Industry 4.0 and a digital twin of the European coast. Python is my main language, along with C, Matlab and Java.

Currently

PhD project

Hamelin

A no-code, protocol-aware AutoML desktop application for clinical research. Clinical researchers without coding skills can build, evaluate and document predictive models that respect clinical protocol structures which generic AutoML tools ignore. It is the core of my doctoral thesis, within the funded project Human-guided automated machine learning for clinical studies (University of Cantabria, 2024–2028).
